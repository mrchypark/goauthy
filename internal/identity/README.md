# identity

## Overview
`identity` persists and manages local user accounts, password credentials and expiry/history, password-reset challenges, passkey-only authentication modes, external/federated identity links, browser login locations and revoke codes, user profile claims/values, and SCIM user/group/tombstone projections in Rhiza.

## Invariants
- Usernames are stored only in canonical ASCII form and subjects are bounded to 512 bytes ([store.go:SchemaStatements](file:///Users/cypark/Documents/project/goauthy/internal/identity/store.go#L29-L60)).
- Guarded mutations (`*WithGuard`, `DeleteUserWithGuard`, `UpdateUserWithGuard`, `UpdateSelfProfileWithGuard`, `LinkExternalWithGuard`, `UnlinkExternalWithGuard`, `ConvertToPasskeyOnlyWithGuard`) enforce caller-supplied SQL authorization predicates inside the same Rhiza transaction; deletion protects against removing the last active `goauthy_admin` (`ErrFinalAdmin`) ([store.go:ErrFinalAdmin](file:///Users/cypark/Documents/project/goauthy/internal/identity/store.go#L46-L48)).
- Password reset tokens are stored as SHA-256 digests bound to `password_generation`, browser binding digest, and single-use consumption attempts ([store.go:SchemaStatements](file:///Users/cypark/Documents/project/goauthy/internal/identity/store.go#L84-L98)).
- `ListSCIMUsers` and `ListSCIMGroups` project non-secret identity/RBAC views deterministically for outbound SCIM reconciliation ([scim.go:ListSCIMGroups](file:///Users/cypark/Documents/project/goauthy/internal/identity/scim.go#L37-L85)).

## Side Effects
- Executes linearizable queries and replicated mutations against Rhiza tables (`identity_users`, `identity_user_profiles`, `identity_password_history`, `identity_password_reset_tokens`, `identity_authentication_modes`, `rbac_principal_versions`, `scim_user_tombstones`, `scim_user_tombstone_providers`, and related login/external-link tables).
- Seals/opens login-revoke code envelopes via `oidc.Keyring`, hashes passwords via `credential.Hasher`, and records metrics when `metrics.Registry` is configured.
