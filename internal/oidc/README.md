# oidc

## Overview
`oidc` manages the local AES-256-GCM master `Keyring` and envelope encryption (`GAOK` / `GAOP`), Ed25519 OIDC signing-key lifecycle and rotation (`EnsureSigningKey`, `SigningKeyRotationWorker`), EdDSA JWT signing and verification (ID, access, and backchannel logout tokens), OAuth/OIDC discovery and JWKS HTTP handlers, and master-key reference inspection/rewrap batches.

## Invariants
- `NormalizeIssuer` requires `https` (except loopback `http`), canonical path without trailing slash/query/fragment/userinfo ([keys.go:NormalizeIssuer](file:///Users/cypark/Documents/project/goauthy/internal/oidc/keys.go#L127-L167)).
- `LoadKeyring` requires 32-byte raw-base64url master keys on disk and an active key ID present in the directory; `RemoveKey` refuses to remove the active master key ([keys.go:LoadKeyring](file:///Users/cypark/Documents/project/goauthy/internal/oidc/keys.go#L169-L202), [keys.go:RemoveKey](file:///Users/cypark/Documents/project/goauthy/internal/oidc/keys.go#L78-L105)).
- `SigningKeyRotationWorker.Step` pre-publishes a pending key at least `JWKSCacheMaxAge` (5m) before activation and retires the previous active key for `MinimumSigningKeyRetirement` ([rotation_worker.go:Step](file:///Users/cypark/Documents/project/goauthy/internal/oidc/rotation_worker.go#L55-L85)).
- `InspectMasterKeyReferences` authenticates every live envelope across all 7 storage families with linearizable reads and fails closed with `ErrUnsafeMasterKeyStatus` on any tampered/malformed/unknown-key row ([key_status.go:InspectMasterKeyReferences](file:///Users/cypark/Documents/project/goauthy/internal/oidc/key_status.go#L53-L92)).

## Side Effects
- Reads and deletes master key files in `Keyring.directory`; caches active signing material under `Keyring.mu`.
- Reads and mutates `oidc_signing_keys`, `event_log`, and envelope-encrypted columns across Rhiza tables (`managed_oauth_clients`, `email_outbox`, `identity_login_revoke`, `bootstrap_*`).
- Serves `/.well-known/*` discovery and `/oidc/jwks.json` HTTP responses with `ETag` and `Cache-Control`.
