# 계정 UI 사용 안내

이 문서는 GoAuthy의 로그인, 계정 관리, 기기 승인 화면을 사용하는 사람을 위한 안내입니다. 페이지에 보이는 메뉴와 입력란은 관리자 설정, 계정 기능, 연결 제공자 설정에 따라 달라질 수 있습니다. 화면의 안내 문구와 이름이 이 설명과 다르면 현재 화면에 표시된 값을 기준으로 진행하세요.

## 어디로 이동하나요?

- 로그인하지 않은 상태에서 서비스 홈(`/`)으로 가면 `/account/login`으로 이동합니다.
- 로그인된 일반 사용자는 `/account`에서 계정을 관리합니다. 로그인된 관리자는 관리자 대시보드로 이동합니다.
- `/account/login`에서 로그인하면 서비스 홈으로 돌아가며, 사용자 역할에 맞는 화면으로 이동합니다.
- 계정 화면 위쪽에서 한국어/English를 바꿀 수 있습니다. 홈, 계정, 로그아웃 링크도 같은 곳에 있습니다. 관리자 대시보드 링크는 관리자 계정에만 표시됩니다.

## 계정 로그인

1. `/account/login`에서 사용자 이름과 비밀번호를 입력하고 **로그인**을 누릅니다.
2. 패스키 로그인이 설정되어 있다면 **패스키로 로그인**을 선택하고 브라우저의 보안 키 확인을 완료할 수 있습니다.
3. 관리자가 외부 로그인 제공자를 설정했다면 해당 제공자 버튼도 표시될 수 있습니다.
4. 로그인이 끝나면 서비스 홈으로 돌아갑니다. 일반 사용자는 계정 화면으로, 관리자는 관리자 화면으로 이동합니다.

로그인이 실패하면 입력값을 확인해 다시 시도하세요. 시도 제한 안내가 나타나면 잠시 기다린 뒤 다시 시도합니다. **비밀번호를 잊으셨나요?**와 **계정 만들기** 링크는 서비스에서 해당 기능을 사용할 수 있을 때 표시됩니다. 로그인 화면의 언어 선택은 한국어 또는 English를 지원합니다.

## 가입과 비밀번호 재설정

### 새 계정 만들기

1. 로그인 화면에서 **계정 만들기**를 엽니다. 가입이 제한된 서비스라면 가입 대신 관리자에게 등록 방법을 문의하라는 안내가 표시됩니다.
2. 이메일 주소를 입력합니다. 서비스 정책상 필요한 프로필 항목은 필수로 표시됩니다. 선택 정보는 **선택 정보 추가**를 열어 입력할 수 있습니다. 사용자 이름, 이름, 성, 생년월일, 전화번호, 주소, 우편번호, 도시, 국가, 시간대 항목은 정책과 설정에 따라 일부만 나옵니다.
3. **이메일로 링크 받기**를 누릅니다. 화면에서 보안 확인이 진행됩니다.
4. 받은편지함에서 이메일을 확인하고 안내된 링크를 엽니다. 링크로 이메일을 확인하고 비밀번호를 설정해야 가입이 완료됩니다.

화면에는 주소가 가입 가능한지와 관계없이 받은편지함을 확인하라는 일반 안내가 나올 수 있습니다. 메일이 오지 않으면 스팸함을 확인하고 잠시 기다린 뒤 다시 요청하세요. 너무 많이 시도했다는 안내가 있으면 제한 시간이 지난 뒤 시도합니다. 가입이 차단되었다면 관리자에게 문의하세요.

### 비밀번호 재설정

1. 로그인 화면에서 **비밀번호를 잊으셨나요?**를 엽니다.
2. 계정 이메일을 입력하고 **이메일로 링크 받기**를 누릅니다.
3. 이메일의 재설정 링크를 열고 **링크 확인하고 계속**을 누릅니다.
4. 화면에 표시된 비밀번호 정책을 확인해 새 비밀번호와 확인란을 입력한 다음 **비밀번호 저장**을 누릅니다.
5. 저장이 완료되면 원래 사용하던 앱이나 탭으로 돌아가 새 비밀번호로 로그인합니다.

두 비밀번호가 다르면 다시 입력합니다. 링크가 만료되었거나 유효하지 않으면 재설정 요청부터 다시 시작하세요. 요청 결과를 확인할 수 없다는 안내가 나오면 같은 요청을 연속 제출하지 말고 이메일을 먼저 확인한 다음 새 링크가 필요할 때 다시 요청합니다. 횟수 제한은 잠시 기다린 뒤 재시도합니다.

## 다른 기기에서 로그인 승인하기

기기 코드 로그인은 계정 화면의 **승인된 기기** 관리와 별개입니다. 이 흐름은 TV나 제한된 입력 장치처럼 브라우저에서 직접 로그인하기 어려운 기기를 승인할 때 사용합니다.

1. 로그인하려는 기기에서 로그인을 시작하고 화면에 표시된 사용자 코드와 확인 주소를 확인합니다.
2. 브라우저에서 `/oidc/device/verify`를 열고 코드가 입력되어 있지 않으면 **기기 코드**를 입력한 뒤 **요청 검토**를 누릅니다. 로그인하지 않았다면 먼저 계정 로그인 화면으로 이동합니다.
3. 검토 화면에서 요청 앱의 클라이언트 ID, 리소스(표시되는 경우), 요청 권한 범위를 확인합니다.
4. 직접 시작한 요청이고 코드가 기기 화면과 일치할 때만 **기기 승인**을 누릅니다. 모르는 요청이거나 정보가 맞지 않으면 **요청 거부**를 선택합니다.
5. 완료되면 기기로 돌아갑니다. 기기 화면의 요청 상태가 승인 또는 거부로 바뀝니다.

코드를 사용할 수 없다는 오류가 나면 오타를 확인하세요. 코드는 만료되거나 이미 사용 또는 거부되었을 수 있습니다. 기기에서 새 요청을 시작해 새 코드를 사용합니다. 로그인만으로 승인이 완료되지는 않습니다. 직접 시작하지 않은 요청은 승인하지 마세요.

## 계정 프로필과 보안

계정 화면의 섹션 링크를 사용하면 프로필, 보안, 패스키, 연결, 기기 항목으로 이동합니다. 일부 섹션은 계정 기능이나 서버 설정에 따라 숨겨집니다.

### 기본 사용자 이름

1. **사용자 이름**에 새 값을 입력하고 **사용자 이름 저장**을 누릅니다.
2. 서비스가 정한 사용자 이름 규칙과 길이 제한(최대 128자)에 맞지 않으면 오류 안내에 따라 수정합니다.
3. 저장 성공 메시지가 나오면 변경이 완료된 것입니다.

### 비밀번호 변경

1. **현재 비밀번호**, **새 비밀번호**, **새 비밀번호 확인**을 입력합니다.
2. 두 새 비밀번호를 동일하게 입력하고 **비밀번호 변경**을 누릅니다.
3. 성공 안내가 나오면 다음 로그인부터 새 비밀번호를 사용합니다.

현재 비밀번호가 맞지 않거나 서버 정책을 만족하지 못하면 오류가 표시됩니다. 값을 다시 확인하세요. 요청 중에는 중복 제출할 수 없습니다.

### 개인 정보와 사용자 정의 계정 필드

필드를 사용할 수 있을 때 **개인 정보** 섹션에 관리자 설정으로 제공된 항목이 표시됩니다. 화면의 각 라벨과 값 형식은 서비스 설정에서 온 것이므로 이름이나 선택값을 임의로 바꾸지 마세요.

1. 필요한 항목을 수정하고 **정보 저장**을 누릅니다.
2. 빈 값은 지우기로 저장됩니다. 기존 값이 숫자, 불리언 또는 JSON 형태였다면 같은 형식을 유지합니다. 구조화된 값은 유효한 JSON이어야 합니다.
3. 성공 메시지로 저장 여부를 확인합니다.

필드를 불러오지 못했다면 저장이 차단될 수 있습니다. 페이지를 새로고침해 다시 불러오세요. JSON 오류가 나오면 구조화된 필드의 따옴표와 괄호를 확인합니다. 계정에서 편집 가능한 필드가 없으면 이 섹션이 표시되지 않을 수 있습니다.

### 패스키 추가와 제거

패스키 섹션은 계정에서 패스키 기능을 사용할 수 있을 때 표시됩니다. 브라우저와 기기에 패스키 기능이 있어야 합니다.

1. **새 패스키 이름**을 입력하고 **패스키 추가**를 누릅니다.
2. 아직 패스키가 없다면 현재 비밀번호를 입력합니다. 기존 패스키가 있으면 기존 패스키로 추가 작업을 확인합니다.
3. 브라우저가 안내하는 보안 키, 기기 잠금 또는 패스키 저장 확인을 완료합니다.
4. 성공하면 등록된 패스키 목록에 이름이 표시됩니다.

제거하려면 해당 항목의 **삭제**를 누르고 확인 창에서 동의합니다. 변경을 확인하기 위해 현재 비밀번호 또는 등록된 패스키 확인이 필요할 수 있습니다. 브라우저가 패스키를 지원하지 않으면 지원되는 브라우저와 기기에서 다시 시도하세요. 취소하거나 보안 키 확인을 완료하지 못하면 패스키가 추가/제거되지 않습니다.

### 비밀번호 로그인 끄기와 복원

**비밀번호 없는 로그인** 영역은 계정에 비밀번호와 패스키가 모두 있고 등록된 패스키가 있을 때 표시됩니다.

- 비밀번호 로그인을 끄려면 **비밀번호 로그인 끄기**를 누르고 확인합니다. 등록된 패스키가 계속 계정에 접근할 수 있는지 확인한 뒤 진행하세요. 완료되면 비밀번호 입력은 사용할 수 없게 됩니다.
- 비밀번호 로그인이 꺼진 계정에 **비밀번호 로그인 복원**이 표시될 수 있습니다. 새 비밀번호를 두 번 입력하고 **비밀번호 로그인 복원**을 누른 다음 패스키 확인을 완료합니다. 완료 후 새 비밀번호로 로그인할 수 있습니다.

기능이 정책상 허용되지 않거나 패스키 확인에 실패하면 완료되지 않습니다. 브라우저의 보안 키 요청을 취소했다면 다시 시작할 수 있습니다. 복원 화면에서 요청이 실패하면 새 비밀번호를 다시 입력해야 할 수 있습니다.

## 연결 관리

연결은 관리자가 준비한 컬렉션별로 관리합니다. 메타데이터는 연결을 설명하는 일반 정보입니다. 토큰, 비밀번호, API 키, 클라이언트 시크릿을 메타데이터 필드에 입력하지 마세요.

### 연결 만들기, 편집, 새로고침, 취소, 삭제

1. **컬렉션 새로고침**을 눌러 사용 가능한 컬렉션을 불러옵니다.
2. 컬렉션을 선택하고 표시된 필드를 채웁니다. 필수 항목을 비워 두지 말고, 정수 필드는 정수로 입력합니다. 선택 항목은 화면의 **설정 안 함** 값을 사용할 수 있습니다.
3. **연결 만들기** 또는 **연결 저장**을 눌러 저장합니다. 성공하면 연결 목록이 다시 표시됩니다.
4. 기존 연결을 바꾸려면 **편집**을 누르고 변경 사항을 저장합니다. 편집 중 그만두려면 **편집 취소**를 누릅니다.
5. 목록을 다시 가져오려면 **컬렉션 새로고침**을 누릅니다. 연결을 지우려면 **삭제**를 누르고 확인합니다.

숫자 형식이 잘못되었거나 필수값이 없으면 요청을 보내기 전에 오류가 표시됩니다. 연결이 다른 곳에서 바뀌었다는 안내가 나오면 새로고침하고 최신 값을 다시 확인한 뒤 편집하세요. 브라우저가 정수 값을 안전하게 처리할 수 없는 연결은 편집이 비활성화됩니다. 비활성화된 컬렉션은 새 연결을 만들거나 수정할 수 없습니다.

### API 키 연결

API 키 컬렉션은 먼저 위 단계대로 연결을 저장해야 합니다. 그런 다음 해당 연결에서 **API 키 관리**를 엽니다.

1. 제공자 설정에 표시된 키 헤더, 허용 작업, 응답 필드, 설정 요약을 검토합니다.
2. 표시된 설정으로 키를 저장하는 데 동의하는 확인란을 선택합니다.
3. API 키 입력란에 키를 입력하고 **API 키 저장**을 누릅니다. 입력값은 화면에서 숨겨지며 저장 시 입력란이 지워집니다.
4. 이미 등록된 키를 저장하면 새 키로 교체됩니다. 현재 상태 문구로 등록 여부를 확인합니다.

제공자 설정을 불러오지 못하면 새 키 저장을 진행하지 마세요. 패널을 닫았다 다시 열어 설정을 검토합니다. 기존 키 취소는 별도로 가능할 수 있습니다. **API 키 취소**는 GoAuthy 쪽의 저장된 연결 키를 취소하며 제공자에 있는 원본 키는 변경하지 않습니다. 취소한 GoAuthy 키는 다시 등록할 수 없다는 안내가 있으니 복구 대신 새 연결이 필요할 수 있습니다. API 키 저장 자체는 소비자 서비스의 사용 권한을 주지 않습니다. 그런 권한은 **서비스 액세스 관리**에서 별도로 부여합니다.

### OAuth 연결

OAuth 컬렉션과 제공자가 설정되어 있으면 연결의 **OAuth 관리**를 엽니다.

1. 연결 상태와 제공자 정보를 확인합니다. 초안 상태라면 제공자를 선택하고 **인증 시작**을 누릅니다.
2. **제공자 인증 열기**를 눌러 제공자 사이트에서 로그인과 동의를 완료합니다.
3. 계정 페이지로 돌아와 **상태 확인**을 누릅니다. 연결 준비가 완료되면 계정과 허용 범위가 표시됩니다.
4. 상태가 준비된 경우 필요할 때만 **액세스 새로고침**을 사용합니다. 제공자와 실제 토큰 교환이 한 번 수행됩니다.
5. 로컬 연결을 끊을 때는 **로컬에서 취소**를 사용합니다. 다시 연결하려면 취소 상태에서 **재연결 준비**를 누른 뒤 새 인증을 별도로 시작합니다.

새 인증을 시작하지 않았다면 인증 URL이 나타나지 않는 것이 정상입니다. 상태를 읽지 못했거나 작업에 실패하면 **상태 확인**으로 현재 상태를 다시 확인합니다. 마지막 토큰 교환 결과가 불확실하다는 안내가 나오면 새로고침을 반복하지 마세요. 먼저 상태를 확인하고, 필요한 경우 로컬에서 취소한 뒤 재연결 절차를 사용합니다. 로컬 취소는 제공자 토큰 자체를 취소하지 않습니다.

### 서비스 액세스 권한(그랜트)

**서비스 액세스 관리**는 연결의 자격 증명이나 등록된 작업을 소비자 서비스가 사용할 수 있도록 별도 동의를 관리합니다. 연결이 준비되어 있고 제공자 설정을 읽을 수 있어야 새 권한을 만들 수 있습니다.

1. 서비스 액세스 패널을 열어 기존 권한, 소비자, 용도, 리소스, 만료 시점을 검토합니다.
2. 소비자 클라이언트 ID, 용도, 만료 시점을 입력합니다. ID는 관리자가 등록한 소비자 ID여야 합니다. 용도는 공백을 앞뒤에 두지 말고 256바이트 이하로 작성합니다. 만료는 현재 이후이면서 30일 이내여야 합니다.
3. 표시된 연결과 작업 또는 계정 및 범위를 확인하고 동의 확인란을 선택한 뒤 **서비스 액세스 만들기**를 누릅니다.
4. OAuth 연결에서는 액세스 토큰이 소비자에게 전달되는 모드이며, 전체 허용 범위에 접근할 수 있다는 경고를 읽으세요. 용도는 설명이며 접근 범위를 제한하지 않습니다. 필요한 경우에만 이후 토큰 갱신 허용을 선택합니다.
5. 성공 후 목록에 새 권한이 나타납니다. 기존 권한을 끝내려면 **액세스 취소**를 누르고 확인합니다.

API 키 연결은 등록된 작업을 프록시하는 모드입니다. OAuth 권한은 소비자에게 액세스 토큰을 전달하므로 범위가 더 넓을 수 있습니다. 동의하지 않는다면 확인란을 선택하지 말고 패널을 닫으세요. 다른 곳에서 권한이 변경되었다는 오류가 나오면 패널을 닫았다 다시 열어 최신 목록과 설정을 확인합니다. 취소는 이후 사용을 막지만 이미 전달된 자격 증명이나 완료된 요청을 되돌릴 수 없습니다. 검토만 하려면 **닫기**를 누르면 됩니다.

## 승인된 기기 확인과 취소

이 목록은 계정에 연결된 OAuth 로그인 세션을 관리합니다. 앞 절의 기기 코드 승인과 다릅니다.

1. **승인된 기기**에서 클라이언트 ID, 요청 범위, 생성 시점을 확인합니다. 기기 이름, 위치, 마지막 사용 정보는 제공되지 않을 수 있습니다.
2. 최신 목록이 필요하면 **기기 새로고침**을 누릅니다.
3. 더 이상 허용하지 않을 항목에서 **기기 취소**를 누르고 확인합니다.
4. 성공 메시지가 표시되고 목록이 다시 불러와지면 취소된 시각이 나타나며 해당 기기의 취소 버튼은 사라집니다.

목록을 불러오지 못하면 새로고침하고 로그인 세션을 확인하세요. 이미 취소된 기기는 다시 취소할 수 없습니다. 이 기능은 API 키나 OAuth 연결 자격 증명을 취소하는 기능과 서로 다릅니다.

## 로그아웃과 계정 삭제

- 계정 화면 상단의 **로그아웃**을 선택하면 GoAuthy 로그아웃 절차가 시작됩니다. 다시 계정에 접근하려면 로그인해야 합니다. 로그아웃 후에도 외부 제공자 세션이 유지될 수 있으므로 공용 기기라면 브라우저도 함께 잠그거나 로그아웃하세요.
- **계정 삭제**는 서비스에서 허용한 경우에만 표시됩니다. 계정 이메일 전체를 확인란에 입력하고 **내 계정 삭제**를 누른 다음 확인 창에서 동의해야 합니다. 삭제는 영구적입니다. 성공 화면으로 바뀌면 완료된 것입니다. 오류가 나면 상태를 확인하기 전까지 같은 삭제 요청을 반복하지 말고 관리자에게 문의하세요.

## 확인된 범위와 미확인 환경

계정 JavaScript 테스트는 모의 요청과 모의 DOM을 사용하는 자동 검사이며 실제 서비스 연결이나 브라우저 호환성을 보장하지 않습니다. 메타데이터만 사용하는 연결 만들기/편집/새로고침/취소와 서비스 액세스 패널 열기/닫기를 실제 브라우저에서 확인했습니다. 상세 실행 근거는 [검증 원장](ui-functional-audit.md)을 참고하세요. 외부 OAuth 제공자 인증과 실제 키 저장, 서비스 액세스 만들기/취소, 이메일 전달과 링크 만료, 실제 기기 코드 교환, 보안 키·패스키 하드웨어 동작은 이 안내 작업에서 검증하지 않았습니다. 메뉴나 절차가 다르면 관리자 설정 또는 현재 화면의 안내를 확인하세요.
