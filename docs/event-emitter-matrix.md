# Event emitter matrix

This is a source-checked checklist of the 24 values accepted by
`internal/eventlog.Type`. “Emitter” means a production call that constructs
and persists an `eventlog.Event`; declarations, API documentation, migrations,
and audit records do not count as lifecycle emitters.
All rows reuse the existing `internal/eventlog` model/guarded SQL and Rhiza;
stdlib HTTP/JSON/time/crypto handles transport and IDs. Module anchors below are
integration candidates, not a substitute for checking the upstream trigger.
Live and deterministic evidence is maintained in [status](status.md).

## Pinned upstream reference

Rauthy v0.36.2 (commit `dd61ac3c84d6b238108dc8438b53043b5177a662`) constructs
`UserPasswordReset` and `UserEmailChange` with caller-provided text/IP and
configured event levels. Its defaults for both levels are `Notice`:

- [constructors](https://github.com/sebadob/rauthy/blob/dd61ac3c84d6b238108dc8438b53043b5177a662/src/data/src/events/event.rs)
- [password-reset call, including `NewUser` and `PasswordReset`](https://github.com/sebadob/rauthy/blob/dd61ac3c84d6b238108dc8438b53043b5177a662/src/service/src/password_reset.rs)
- [configured defaults](https://github.com/sebadob/rauthy/blob/dd61ac3c84d6b238108dc8438b53043b5177a662/src/data/src/rauthy_config.rs)

The matrix intentionally distinguishes eventlog emitters from the separate
audit subsystem and from event type declarations/API documentation.
